# Contributing

### How to contribute

1. Open an issue to report a bug, suggest an improvement, or discuss a larger change.
2. Create a branch for your contribution.
3. Keep changes focused and easy to review.
4. Open a pull request describing what you changed and why.

For small fixes, such as typos or documentation improvements, you can submit a pull request directly.

### Before submitting a pull request
1. Check that the pages or notebooks you changed render and run as expected.
2. Add or update documentation when needed.
